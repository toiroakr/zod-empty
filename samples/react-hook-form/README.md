# @zod-empty/react-hook-form

zod-empty sample with [react-hook-form](https://github.com/react-hook-form).

## Usage

Use Node.js 22.13 or newer and the pnpm version pinned in the root package.json.
Run these commands from the repository root:

```shell
pnpm install --frozen-lockfile
pnpm build
pnpm --filter @zod-empty/react-hook-form dev
```

Build the sample with `pnpm build:sample`. The sample uses the local workspace package and Zod 4.
